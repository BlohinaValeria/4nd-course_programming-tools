## 4nd-course_programming-tools

# Тема: разработка ETL-конвейера для нормализации номенклатурных позиций и оценки результатов на основе данных 1С.

В этой папке собраны диаграммы, небольшой пример программы на Python, описание работы и макет интерфейса.

## Файлы
- `diagrams/use_case.png` — кто и для чего будет пользоваться программой.
- `diagrams/class_diagram.png` — основные классы программы.
- `diagrams/sequence.png` — порядок действий при обработке данных.
- `diagrams/state.png` — состояния задания.
- `diagrams/activity.png` — схема самого процесса обработки.
- `src/pipeline.py` — пример реализации части логики на Python.
- `report.md` — описание предметной области и диаграмм.
